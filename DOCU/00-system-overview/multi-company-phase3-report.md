# تقرير المرحلة 3 — الواجهة متعددة الشركات (UNIQUE / ELITE)

التاريخ: 2026-09-20 · النطاق: **Frontend فقط** · المرجع التفصيلي: [operating-companies.md](./operating-companies.md)

لم يُعدَّل أي من: Prisma، migrations، مسارات/خدمات الباكيند، TARS، دورة حياة العقد،
منطق Car-Out / Car-In، الدفع، التجديد، الإرجاع.

---

## 1. الخلاصة

هوية الشركة التشغيلية (UNIQUE / ELITE) صارت مكتملة من الواجهة حتى الوثيقة الرسمية:
اختيار إلزامي عند إنشاء المركبة، علامة هوية وفلتر في الأسطول والعقود، اسم قانوني
صحيح في A4، وسياق الشركة في Car-Out / Car-In. جولة التحقق النهائية خضراء، وأُصلح
خلل تخطيط ظهر في جدول العقود أثناء المراجعة.

## 2. ما نُفِّذ في المرحلة 3

### 2.1 وحدة الشركات التشغيلية

`src/modules/operating-companies` تتبع معمارية Diamond كما هي:

```
Component → Hook → Zustand Store → Domain API → Central API Client → Fastify
```

- `operating-companies.api.ts` — نداء واحد إلى `GET /operating-companies`.
- `operating-companies.store.ts` — يفلتر `isActive`، ويجمع الطلبات المتزامنة في
  طلب واحد (`inFlight`) حتى لا تُكرِّر كل شاشة النداء.
- `use-operating-companies.ts` — الواجهة الوحيدة للمكوّنات.

لا يوجد `fetch` مباشر داخل أي مكوّن، ولا قيم UNIQUE / ELITE مكتوبة يدويًا في UI.

### 2.2 مكوّن الهوية المشترك

`src/shared/components/company-identity` — شريط لون رفيع + `displayName`، واللون من
`accentColor` الآتي من الباكيند عبر متغيّر `--company-accent`. تصميم مقصود ألّا يشبه
chip الحالة التشغيلية (AVAILABLE / RENTED / PAID…).

الألوان الحالية **مؤقتة**: UNIQUE `#C9A15C`، ELITE `#3E5C76` — تُستبدل من بيانات
الشركة وحدها عند وصول ألوان العلامة الرسمية.

### 2.3 المركبات

| البند | السلوك |
| ----- | ------ |
| Add Vehicle | Select إلزامي للشركة عبر FormBuilder + Shared Select، بلا default صامت، يُرسل `companyId` |
| Edit (الأسعار) | يعرض الشركة **للقراءة فقط**؛ نقل الملكية لا يُعرض من واجهة خاصة بالتسعير |
| بطاقة/تفصيل المركبة | علامة الهوية بجانب اسم المركبة، والاسم يبقى العنصر البصري الأساسي |
| التولبار | فلتر شركة (All / UNIQUE / ELITE) بـ`companyId` على الخادم |
| الحالة | `companyId` في `VehicleFiltersState` و`DEFAULT_VEHICLE_FILTERS` وبناء الاستعلام؛ Clear Filters يعيدها إلى All |

### 2.4 العقود

- الصف والدرج يعرضان `Contract.company` — **تاريخية**، لا تُستنتج من شركة المركبة الحالية.
- فلتر شركة مضاف إلى `ContractFiltersState` و`DEFAULT_CONTRACT_FILTERS` و
  `buildContractsQuery` وعدّاد الفلاتر النشطة و`setCompany` في `use-contracts`.
- الفلتر يدخل نفس الاستعلام المفتاحي القائم: latest-wins gate، تحديث عند focus،
  تحديث عند عودة التبويب، وpolling كل 30 ثانية. لا معمارية طلبات موازية.

### 2.5 العقد الرسمي (A4)

- الرأس يقرأ `officialContractCompanyNames(contract)` من
  `OfficialContractView.header.company` بدل الثوابت.
- التصميم دون تغيير: الكتلة السوداء، الأبعاد، الشعار، كتلة التواصل، الجسم القانوني.
  المتغيّر الوحيد سطرا الاسم القانوني.
- سناب شوت ما قبل تعدّد الشركات: تُسقَط كتلة الشركة من `Contract.company` + lookup
  الباكيند، بلا إعادة كتابة الـJSON المجمّد وبلا أي استنتاج من المركبة.

| الشركة | عربي | إنجليزي |
| ------ | ---- | ------- |
| UNIQUE | شركة دايموند يونيك لتأجير السيارات ذ.م.م ش.ش.و | DIAMOND UNIQUE CAR RENTALS CO. LLC S.O.C |
| ELITE | شركة دايموند إيليت لتأجير السيارات ذ.م.م ش.ش.و | DIAMOND ELITE CAR RENTALS CO. LLC S.O.C |

### 2.6 العهدة والواجهة العامة

Car-Out و Car-In: علامة الشركة في الهيدر السياقي فقط، من `Contract.company`.
لا تغيير في الخطوات أو التواقيع أو الصور أو الدرافت أو الانتقالات.
Public Rental يعرض شركة العقد ولا يسمح للعميل باختيارها.

## 3. الخلل المُصلَح — انحراف علامة الشركة في جدول العقود

### العَرَض

العلامة (UNIQUE) تظهر **بجانب** رقم العقد على السطر نفسه، وتعود تحت الرقم بعد
تحديث المتصفح.

### السبب الجذري

`contracts-table.module.css` كان يحتوي:

```css
.company { display: flex; width: max-content; margin-block-start: 5px; }
```

وهو تجاوز، من CSS module آخر، لقاعدة المكوّن المشترك `.identity { display: inline-flex }`.
القاعدتان بصنف واحد (نفس الـspecificity)، وتُبنيان في **chunkين منفصلين**:

- `company-identity-module__*` → chunk أ
- `contracts-table-module__*` → chunk ب

الفائز يتحدّد بترتيب تحميل الأوراق، وهو يختلف بين التنقّل الناعم والتحميل الكامل.

### البرهان

على بناء production قبل الإصلاح، نُقلت ورقة `company-identity` إلى آخر `<head>`:

```
ORDER as-served      display=flex         sameLine=false   ← الحالة الصحيحة
ORDER identity-last  display=inline-flex  sameLine=true    ← الخلل المُبلَّغ
```

### الإصلاح

التخطيط انتقل إلى الحاوية بدل تجاوز المكوّن المشترك:

```tsx
<span className={styles.numberCell}>
  <span className={styles.numberLine}>
    <span className={styles.number} dir="ltr">{contract.contractNumber}</span>
    {gpsDot}
  </span>
  <CompanyIdentity company={contract.company} compact />
</span>
```

`.numberCell` عمود flex؛ العلامة صارت flex item تُبلَّك تلقائيًا أيًا كان ترتيب الأنماط.
`.company` حُذفت. بعد الإصلاح، وبنفس فرض الترتيب المعاكس: `display=flex`، `sameLine=false`.

### القاعدة الدائمة

`CompanyIdentity` مكوّن `inline-flex`. السطح الذي يحتاج ترتيبًا مختلفًا يعطي
**الحاوية** التخطيط، ولا يعيد تعريف `display` للمكوّن المشترك من موديول آخر.

### تثبيت السبك (Test hardening)

ظهرت حالتا هشاشة في سبك الميزة، وأُصلحتا:

1. **429 على تسجيل الدخول.** `/auth/login` يسمح بـ5 محاولات في الدقيقة لكل مُنادٍ
   (`RATE_LIMIT_AUTH_MAX`)، والسبك كان يسجّل الدخول ست مرات فتفشل الأخيرة بصيغة
   "Invalid credentials". صار تسجيل دخول واحدًا يُعاد استخدامه عبر `storageState`.
2. **اعتراض RSC prefetch.** النمط `**/vehicles?*` كان يلتقط طلبات Next
   (`/ar/vehicles?_rsc=`) فيفشل بـ`SyntaxError: Unexpected non-whitespace character
   after JSON` على بناء الإنتاج. النمط صار مقيّدًا بأصل الباكيند.

وأُضيف حارس انحدار دائم يؤكد بقاء العلامة تحت سطر رقم العقد.

## 6. معلّقات معروفة (خارج نطاق هذه المرحلة)

1. **عقود بلا `officialContract` في السناب شوت** — مثل `DE-2026-000017`، سناب شوته
   `vehicle|customer|commercial|termsVersion|contractNumber` فقط. لا تعرض A4 إطلاقًا
   وتظهر رسالة «النسخة الموقّعة غير متاحة». بيانات أقدم من ميزة الوثيقة نفسها، وعلاجها
   backfill في الباكيند لا في الواجهة.
2. **نص بديل الشعار** — ملف شعار رأس العقد يحمل "DIAMOND ELITE RENT CAR". تعارض
   براندينج قائم قبل هذا العمل؛ أُبلِغ ولم يُعالَج لأن المطلوب كان اسم الشركة فقط.
3. **TARS** — التوجيه واعٍ بالشركة، والمزوّدان غير مُهيّأين ويفشلان مغلقين.
4. **ألوان العلامة** — `#C9A15C` و`#3E5C76` مؤقتتان.
5. **لا مركبة ELITE في بيانات التطوير** — تُضاف من الواجهة عند الحاجة؛ البذرة لا تنشئها
   حتى لا يتغيّر عدد أسطول الـDemo الذي يتحقق منه bootstrap.
